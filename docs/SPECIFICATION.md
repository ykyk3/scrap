# Scrap - シンプルURL保存アプリ仕様書

## 1. 概要

URLを保存してメモやタグで整理するシンプルなWebアプリケーション。

### ターゲット
- 気になるURLをさっと保存したい人
- リンク集を整理したい人

---

## 2. 機能要件

### 2.1 スクラップ管理（コア機能）

| ID | 機能 | 説明 | 優先度 |
|----|------|------|--------|
| S-001 | URL保存 | URLを入力して保存 | 必須 |
| S-002 | タイトル自動取得 | URLからページタイトルを取得 | 必須 |
| S-003 | メモ追加 | 自由記述のメモを付与 | 必須 |
| S-004 | 一覧表示 | 保存したURLのリスト表示 | 必須 |
| S-005 | 編集 | タイトル・メモの編集 | 必須 |
| S-006 | 削除 | スクラップの削除 | 必須 |
| S-007 | 元URLを開く | 保存したURLを新規タブで開く | 必須 |

### 2.2 タグ機能

| ID | 機能 | 説明 | 優先度 |
|----|------|------|--------|
| T-001 | タグ付け | スクラップに複数タグを設定 | 必須 |
| T-002 | タグ一覧 | 作成したタグの一覧表示 | 必須 |
| T-003 | タグでフィルタ | 特定タグで絞り込み | 必須 |
| T-004 | タグ編集 | タグ名の変更 | 高 |
| T-005 | タグ削除 | タグの削除 | 高 |

### 2.3 検索・整理

| ID | 機能 | 説明 | 優先度 |
|----|------|------|--------|
| F-001 | キーワード検索 | タイトル・メモ・URLから検索 | 高 |
| F-002 | ソート | 保存日時順（新しい/古い） | 高 |

## 3. データモデル

```
┌─────────────────┐       ┌─────────────┐
│     Scrap       │       │     Tag     │
├─────────────────┤       ├─────────────┤
│ id              │       │ id          │
│ url             │       │ name        │
│ title           │       │ created_at  │
│ memo            │       └──────┬──────┘
│ created_at      │              │
│ updated_at      │              │
└────────┬────────┘              │
         │                       │
         │    ┌──────────────┐   │
         └────┤  ScrapTag    ├───┘
              ├──────────────┤
              │ scrap_id     │
              │ tag_id       │
              └──────────────┘
```

### テーブル定義

#### scraps
| カラム | 型 | 説明 |
|--------|-----|------|
| id | TEXT (UUID) | PK |
| url | TEXT | 保存したURL |
| title | TEXT | ページタイトル |
| memo | TEXT | メモ（nullable） |
| created_at | DATETIME | 作成日時 |
| updated_at | DATETIME | 更新日時 |

#### tags
| カラム | 型 | 説明 |
|--------|-----|------|
| id | TEXT (UUID) | PK |
| name | TEXT | タグ名（UNIQUE） |
| created_at | DATETIME | 作成日時 |

#### scrap_tags
| カラム | 型 | 説明 |
|--------|-----|------|
| scrap_id | TEXT | FK → scraps |
| tag_id | TEXT | FK → tags |

## 4. API仕様

### スクラップ

| メソッド | エンドポイント | 説明 |
|----------|----------------|------|
| GET | /api/scraps | 一覧取得（?tag=xxx, ?q=xxx でフィルタ） |
| POST | /api/scraps | 新規作成 |
| GET | /api/scraps/:id | 詳細取得 |
| PATCH | /api/scraps/:id | 更新 |
| DELETE | /api/scraps/:id | 削除 |

### タグ

| メソッド | エンドポイント | 説明 |
|----------|----------------|------|
| GET | /api/tags | タグ一覧 |
| POST | /api/tags | タグ作成 |
| PATCH | /api/tags/:id | タグ更新 |
| DELETE | /api/tags/:id | タグ削除 |
