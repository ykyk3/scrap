# Scrap - スクラップアプリ仕様書

## 1. プロジェクト概要

### 1.1 目的
Pocketに類似した「後で読む」サービスを提供するWebアプリケーション。
ユーザーがWebページのURLを保存し、いつでもどこでも読み返せる環境を提供する。

### 1.2 ターゲットユーザー
- 情報収集を頻繁に行うナレッジワーカー
- 記事やブログを後で読みたいユーザー
- リサーチ資料を整理したい学生・研究者

### 1.3 主要な価値提案
- シンプルで高速なURL保存体験
- 記事本文の自動抽出・保存
- 柔軟なタグ付けと検索機能
- オフライン対応

## 3. 非機能要件

### 3.1 パフォーマンス
- 記事一覧の初期表示: 1秒以内
- URL保存から記事抽出完了: 5秒以内
- 検索結果表示: 500ms以内

### 3.2 スケーラビリティ
- 1ユーザーあたり最大10,000記事
- 同時接続ユーザー: 初期1,000人想定

### 3.3 セキュリティ
- HTTPS必須
- パスワードのハッシュ化（bcrypt）
- CSRF対策
- XSS対策
- レートリミット（API）

### 3.4 可用性
- 目標�kind: 99.9%
- 自動バックアップ（日次）

## 6. 技術スタック

### 6.1 フロントエンド
- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **状態管理**: React Query (TanStack Query)
- **UIコンポーネント**: shadcn/ui

### 6.2 バックエンド
- **フレームワーク**: Next.js API Routes (Route Handlers)
- **ORM**: Prisma
- **認証**: NextAuth.js (Auth.js)
- **バリデーション**: Zod

### 6.3 データベース
- **本番**: PostgreSQL (Supabase or Neon)
- **開発**: SQLite or PostgreSQL (Docker)

### 6.4 記事抽出
- **ライブラリ**: @extractus/article-extractor or mozilla/readability

### 6.5 インフラ
- **ホスティング**: Vercel
- **データベース**: Supabase / Neon
- **CDN**: Vercel Edge Network
